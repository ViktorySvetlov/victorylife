# VictoryLife — шаг 17: перенос localStorage в Supabase

Что изменено:

- Добавлен файл `lib/cloudStore.ts`.
- Страницы `dashboard`, `today`, `analytics`, `goals`, `achievements`, `coach`, `settings` теперь используют Supabase, если пользователь вошёл через Google.
- Если пользователь не вошёл, сайт продолжает работать как демо через localStorage.
- Задачи, отметки дня, комментарий дня, цели и достижения теперь сохраняются в Supabase для авторизованного пользователя.

## Как применить

1. Скопируй файлы из этого архива поверх старого проекта.
2. В VS Code открой терминал.
3. Запусти локально:

```powershell
npm run dev
```

4. Проверь вход через Google.
5. Отметь день на `/today`.
6. Проверь Supabase → Table Editor:
   - `tasks`
   - `daily_logs`
   - `task_completions`
   - `goals`
   - `user_achievements`

## Как отправить изменения на GitHub и Vercel

```powershell
git add .
git commit -m "Move VictoryLife data to Supabase"
git push
```

Vercel сам пересоберёт сайт после push.

## Удаление лишних задач

В этой версии пользователь может убрать любое задание из ежедневного списка:

1. Открыть `Настройки`.
2. В блоке `Все задания` выбрать категорию или оставить `Все`.
3. Нажать `Убрать` напротив задания.
4. Подтвердить действие.

Если пользователь вошёл через Google, задача в Supabase не удаляется жёстко — у неё меняется поле `is_active` на `false`. Это безопаснее для истории отметок. Если пользователь не вошёл, задача удаляется из `localStorage`.

Кнопка `Вернуть стандартные` возвращает стандартные задания без сброса целей и истории.
